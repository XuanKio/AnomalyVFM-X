# Quy tắc tài liệu

- Viết tiếng Việt rõ ràng; tên class, hàm, CLI flag và đường dẫn giữ nguyên.
- Mỗi tài liệu phải nêu: mục đích, thành phần liên quan, cách chạy, đầu vào/đầu
  ra, giới hạn và checklist xác minh.
- Lệnh Windows dùng PowerShell. Lệnh Linux chỉ thêm khi đã được xác minh.
- Không ghi thông số benchmark tự suy đoán. Phân biệt số từ paper, số đo local và
  ước lượng.
- Khi hành vi code thay đổi, cập nhật tài liệu cùng commit.
- `docs/README.md` là chỉ mục và phải liên kết mọi tài liệu cấp cao mới.
